# Claude Code Usage Guide

This document provides guidelines for using AI assistance (like Claude Code or Gemini) for the development of this project.

## Principles

- **AI as an Assistant:** Use AI as a pair programmer or a knowledgeable assistant, not as a replacement for understanding the code.
- **Spec-Driven:** All implementation should be driven by the specifications in the `specs` directory. Do not ask the AI to invent new features.
- **Review and Understand:** Always review, understand, and test any code generated by the AI. You are responsible for the code you commit.

## Workflow

1.  **Task First:** Start with a task from `tasks.md`.
2.  **Prompting:** When prompting the AI, provide the relevant context, such as the task description, the code from the relevant files, and the overall architecture.
3.  **Generate and Refine:** Use the AI to generate code snippets or to suggest implementations. Refine the generated code to match the project's style and conventions.
4.  **Test:** Manually test the changes to ensure they work as expected.
5.  **Commit:** Commit the changes with a clear message that references the task ID.
